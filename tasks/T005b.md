## Task
Write the determinism lint.

## Crate(s)
None. Creates `tools/lint/determinism.py` only.

## Purpose
Machine-enforce the determinism rules in AGENTS.md. These rules cannot be
checked by the compiler and are invisible in review, so they need a guard.

## Interface
`python tools/lint/determinism.py` from the repo root.
Exit 0 if clean, exit 1 otherwise. On failure print one line per violation:
`VIOLATION <file>:<line> <rule-name> <the offending line, trimmed>`

## Behaviour
Scan every `.rs` file under `crates/crpg-rules/` and `crates/crpg-sim/`.

Rules for BOTH crates:
- no `HashMap` or `HashSet` (use IndexMap or BTreeMap)
- no `SystemTime`, `Instant`, or `std::time::` (wall clock is not sim time)
- no `std::thread`
- no `rand::` or `thread_rng` (use crpg_core's seeded RNG)

Rules for crpg-rules ONLY:
- no `f32` or `f64` (rules maths uses integers or fixed-point)

Skip lines that are comments. Skip any line ending in
`// determinism-ok: <reason>` and require a non-empty reason.

## Constraints
- Standard library only. Line-based scanning is fine; do not parse Rust.
- Under 150 lines.

## Test
Add `tools/lint/test_determinism.py` with fixture .rs files covering: a clean
file, each banned pattern, a banned pattern inside a comment (must pass), a
banned pattern with a valid `// determinism-ok:` escape (must pass), an escape
with no reason (must fail), and `f64` in crpg-sim (must pass) versus in
crpg-rules (must fail).
`python tools/lint/test_determinism.py` must pass.

## Definition of done
- Both scripts run clean on the current repo.
- A new CI job runs the lint, added in the same commit as the script.

## Out of scope
Do not touch any Rust file. Do not touch deps.py. Do not add a Cargo dependency.
