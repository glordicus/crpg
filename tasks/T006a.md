## Task
Give `crpg-core` its error type, `EntityId`, and `GenerationalArena<T>`.

## Crate(s)
`crpg-core` (only).

## Purpose
The identity primitive the whole simulation is addressed by. Per ADR-0006
Decision 1, the arena that issues and validates ids lives here rather than in
`crpg-sim`, so that id-reuse safety is testable (spec §19.1 item 2) and so
T007's `World` gets an already-property-tested entity arena instead of writing
a second one. This is the first task in the crate, so it also establishes
`Cargo.toml`, the module layout, and `crpg-core/AGENTS.md`.

## Interface

```rust
// crates/crpg-core/src/error.rs
#[derive(Debug, thiserror::Error, PartialEq, Eq, Clone)]

pub type Result<T> = core::result::Result<T, CoreError>;

// crates/crpg-core/src/entity.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash,
         serde::Serialize, serde::Deserialize)]
pub struct EntityId { /* private: index: u32, generation: u32 */ }

impl EntityId {
    pub const fn index(self) -> u32;
    pub const fn generation(self) -> u32;
}

pub struct GenerationalArena<T> { /* private */ }

impl<T> GenerationalArena<T> {
    pub fn new() -> Self;
    pub fn with_capacity(capacity: usize) -> Self;
    pub fn insert(&mut self, value: T) -> EntityId;
    pub fn remove(&mut self, id: EntityId) -> Option<T>;
    pub fn get(&self, id: EntityId) -> Option<&T>;
    pub fn get_mut(&mut self, id: EntityId) -> Option<&mut T>;
    pub fn contains(&self, id: EntityId) -> bool;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    pub fn clear(&mut self);
    pub fn iter(&self) -> impl Iterator<Item = (EntityId, &T)>;
    pub fn iter_mut(&mut self) -> impl Iterator<Item = (EntityId, &mut T)>;
    pub fn ids(&self) -> impl Iterator<Item = EntityId> + '_;
}

impl<T> Default for GenerationalArena<T> { /* = new() */ }
// Serialize/Deserialize where T: Serialize / T: Deserialize, including the
// free list, so a round-trip restores identical future-allocation behaviour.
```

## Behaviour
- Generations start at **1**. An all-zero `EntityId` is never valid. Do not add
  an `EntityId::NONE`; callers use `Option<EntityId>`.
- `remove` bumps the slot's generation and pushes the slot onto a free list.
  Any `EntityId` holding the old generation must from then on return `None`
  from `get`/`get_mut`/`remove` and `false` from `contains`, forever.
- `insert` reuses the lowest-index free slot if one exists, otherwise appends.
  (Lowest-index, not most-recently-freed: reuse order is observable through
  `iter` and must not depend on free/insert history beyond the set of free
  slots.)
- If bumping a slot's generation would overflow `u32`, **retire the slot
  permanently** — do not push it to the free list, do not wrap.
- `iter`, `iter_mut` and `ids` yield **ascending index order**, always.
  Document this as an invariant on the type, not as an implementation note:
  consumers rely on it for determinism.
- `len` counts live entries, not slots.

## Constraints
- Only workspace dependencies: `serde` (with `derive`), `thiserror`.
  Add `proptest = "1"` and `serde_json = "1"` as **dev-dependencies** only —
  both authorised by ADR-0006, and this task is where they enter the
  workspace. No other dependency, and neither may become a normal dependency.
- `#![forbid(unsafe_code)]` and `#![warn(missing_docs)]` stay. Every public
  item gets a doc comment (spec §15.6).
- No `HashMap`/`HashSet`. No floats. No clock, no threads, no I/O.
- `CoreError` variants: add only what this task actually needs. Do not
  pre-populate it with variants for modules that do not exist yet
  (`Fx16_16`, RNG, `Ulid`, interner arrive in T006b–T006e and will extend it).
  If nothing in this task can fail, say so and add the enum with the variants
  the arena genuinely needs, or leave it empty with a doc comment saying why.
- `lib.rs` declares modules and re-exports the public surface. Keep it to
  `pub mod` / `pub use` and the crate doc comment.

## Test
Add `crates/crpg-core/tests/entity.rs`. Unit tests plus these property tests:

1. **Id reuse safety.** Generate a random sequence of insert/remove
   operations. Every id returned by a `remove` is dead: after the operation
   sequence completes, `get` on it is `None` even if its slot index has been
   reissued. Assert specifically that a reissued id compares unequal to the
   retired one.
2. **Arena invariants.** After any random op sequence, `len()` equals the
   number of successful inserts minus successful removes; `contains(id)` agrees
   with `get(id).is_some()` for every id ever issued; `iter().count() == len()`.
3. **Iteration order.** `iter()` indices are strictly ascending, for any op
   sequence.
4. **Serde round-trip.** `deserialize(serialize(arena)) == arena` for a random
   arena, and the round-tripped arena's *next* `insert` returns the same
   `EntityId` the original would have — i.e. the free list survived.
5. **Generation retirement.** A unit test (not a property test) that a slot at
   `u32::MAX` generation is retired rather than wrapped. Construct it directly
   in a `#[cfg(test)]` helper rather than looping 4 billion times.

Command that must pass: `cargo test -p crpg-core`
