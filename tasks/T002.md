## Purpose
Spec `CRPG_ENGINE_SPEC.md` §7.2/§24 (T2) picks `quinn` (QUIC) as the
transport for authoritative movement with client-side prediction of the
local player only (§7.5). Nothing in `crpg-net` should be built on top of
that choice until it is validated end to end, including through a home
router — encryption/reliability/congestion control on a LAN is not the
risky part; a working connection through real-world NAT is.

## Interface
N/A — not a library API. The spike is two standalone binaries (client,
server); no interface is consumed by this workspace.

## Behaviour
In `C:\CRPG\Dev\spike-quic` (fresh repo, `cargo add quinn`):
- **Server**: a fixed 20 Hz tick loop (matching §2.5), receiving
  `MoveTo { position, tick }`-shaped intents over a QUIC stream, integrating
  position naively (no collision, no rules), and sending back the
  authoritative position plus the tick of the last-processed input — the
  shape described in §7.3/§7.5, not the literal final enum.
- **Client**: applies input immediately (prediction), keeps a ring buffer of
  `(tick, input, predicted_position)`, and on receiving a server ack
  discards acknowledged entries and reconciles — snap or ease toward the
  server position and replay unacknowledged inputs if divergence exceeds a
  threshold.
- A **latency/jitter/loss shim** between client and server (a local proxy
  that delays/drops packets, or an equivalent simulated-network crate) so
  the 150 ms RTT / 3% loss condition below can be produced on one machine.
- A **real NAT test**: run the server on a second machine (or a cheap
  always-on host) behind a normal home router with no manual port forward,
  and connect from elsewhere. This is the one condition that cannot be
  simulated locally and is the actual point of the spike.

## Test
- Local, with the shim active at 150 ms RTT and 3% loss: movement reads as
  smooth and reconciliation does not visibly rubber-band.
- A connection succeeds over the public internet through NAT with no manual
  port forwarding on the server side.

## Definition of done
